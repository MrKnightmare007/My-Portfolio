# React Portfolio Website

Welcome to my personal portfolio website! This project showcases my skills, certifications, awards, and provides a way to connect with me. Built with React and modern web technologies, it features interactive components and a sleek design.

## Live Demo

[View the live demo here](https://soumyadiptadasportfolio.vercel.app/) 

## Features

- **Home Section**: A welcoming hero section with a dynamic background.
- **Projects Section**: Displays projects using a ChromaGrid layout.
- **Skills Section**: Highlights technical skills with glass-effect icons.
- **Certifications Section**: Showcases certifications with focus cards.
- **Awards Section**: Features awards in an interactive carousel.
- **Connect Section**: Allows users to connect via social media or email, with a 3D globe visualization.

## Tech Stack

- **Frontend**: React, React Router, Tailwind CSS, Framer Motion
- **Components**: Custom components for Hero, ChromaGrid, GlassIcons, FocusCards, Carousel, SocialMedia, Form, and Globe
- **Icons**: React Icons, Tabler Icons
- **Other Libraries**: React Lazy, Suspense for code splitting

## Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/MrKnightmare007/My-Portfolio.git
   cd My-Portfolio
   cd frontend
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm start
   ```

4. **Open in browser**:
   - Open `http://localhost:3000` (port may vary) to view the app.
